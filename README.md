# Priya's Portfolio

A responsive, single-page portfolio built with HTML, CSS, and JavaScript. Open `index.html` in a browser to preview it. The page includes education, skills, an AgroNexus concept preview, a learning journey, and direct email/GitHub contact links.

- The provided email (`priyadesale6@gmail.com`), GitHub profile (`github.com/priyadesale6-oss`), and LinkedIn profile (`linkedin.com/in/priya-desale-5229a9364`) are linked in the contact section.
- Add a real CV file before enabling the disabled CV button.

- Keep education, skills, project details, and the AI-tool disclosure accurate.

## Publish with GitHub Pages

1. Create a GitHub repository and add `index.html` to its root.
2. In the repository, open **Settings > Pages** and publish from the `main` branch and `/ (root)` folder.
3. Once GitHub Pages finishes publishing, copy the URL shown there. Use that as the hosted website URL in the submission.

The page is static and does not need a build step. Keep `priya-profile.png` beside `index.html` when publishing the site. Google Fonts need an internet connection.

## Prepare the submission PDF

After the site is hosted and its links are updated, open the live URL in a browser and use **Print > Save as PDF**. Name the PDF with the required format, replacing the example with your enrollment number: `<enrollmentNo>.pdf`.
